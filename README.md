# dojo-audio

Audio for the Don't Give Up Dojo practice tools, streamed to the site through jsDelivr.

- `numbers-play-along/G/` – Numbers Play Along, key of G: play-along clips (`play-*.mp4`) and flash-card sections (`flash-*.mp4`), cut from the Numbers Play Along video. AAC 160 kbps; play-alongs -16 LUFS, flash cards -19 LUFS, peaks below -1.6 dBTP.
